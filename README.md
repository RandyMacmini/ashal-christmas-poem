# 🎄 Ashal's Christmas Poem Website

A festive, interactive website featuring a heartfelt Christmas poem with holiday-themed styling and animations.

## ✨ Features

- **Beautiful Christmas Poem**: A touching poem about missing someone during the holidays
- **Festive Styling**: Holiday-themed colors (red, green, gold) with gradient backgrounds
- **Falling Snowflakes**: Animated snowflakes continuously falling in the background
- **Interactive Christmas Lights**: Toggle colorful twinkling lights around the page borders
- **Hover Effects**: Interactive poem stanzas that respond to mouse hover
- **Holiday Music Support**: Built-in audio player for festive background music
- **Responsive Design**: Works beautifully on desktop, tablet, and mobile devices

## 🚀 How to Use

1. **View the Website**: Simply open `index.html` in your web browser
2. **Toggle Christmas Lights**: Click the "✨ Toggle Lights" button to show/hide decorative lights
3. **Play Music**: Click the "🎵 Play Holiday Music" button to start background music (see setup below)

## 🎵 Adding Holiday Music

To enable background music:

1. Download a holiday music MP3 file (royalty-free or your own)
2. Rename it to `holiday-music.mp3`
3. Place it in the same directory as `index.html`
4. Open the website and click the music button!

**Free Music Sources:**
- [Free Music Archive](https://freemusicarchive.org/)
- [YouTube Audio Library](https://www.youtube.com/audiolibrary)
- [Incompetech](https://incompetech.com/music/)

## 📁 File Structure

```
├── index.html      # Main HTML file with the poem structure
├── styles.css      # All styling and animations
├── script.js       # Interactive features (snow, lights, music)
└── README.md       # This file
```

## 🎨 Customization

Feel free to customize the poem or styling:

- **Edit the Poem**: Modify the text in `index.html` within the `.stanza` divs
- **Change Colors**: Update CSS variables in `styles.css` (`:root` section)
- **Adjust Animations**: Modify animation timing in `styles.css`
- **Add More Features**: Extend `script.js` with additional interactive elements

## 💻 Technical Details

- Pure HTML, CSS, and JavaScript (no frameworks required)
- No build process needed
- Works offline after initial load
- Compatible with all modern browsers
